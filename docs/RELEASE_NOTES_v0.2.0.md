# Windows Desktop Portal v0.2.0

这一版重新设计了桌面入口面板，并修复了桌面条目移除后可能再次出现的问题。原有的桌面扫描、拖拽归类、收藏夹、最近访问和系统集成功能继续可用。

## 新界面

- 高明度工业终端视觉：灰白工作区、深色导航和访问记录、尖角边框，以及黄色的当前位置标记。
- 分类、文件卡片和最近访问加入编号与类型提示；细网格、刻度和斜线用于区分区域。
- 面板唤醒和收起时增加分区依次显现与扫描光带，保留原有与 Windows 窗口同步的滑动和淡入淡出。
- 视觉设计借鉴工业终端的信息层级与构图；安装包不包含游戏截图、角色、标志或其他游戏素材。

## 修复与维护

- 从面板移除的桌面条目现在会受到忽略名单保护，不会在下一次桌面同步时重新导入。
- 调整 Rust 开发构建配置，减少调试符号和增量编译缓存的磁盘占用。
- 配置格式仍为 schema v2，桌面文件与快捷方式不会因分类操作而移动。

## 安装

下载并运行 `Windows.Desktop.Portal_0.2.0_x64-setup.exe`。安装包面向 Windows x64，并会检测 WebView2 Runtime。已有安装可使用此安装包更新。

此安装包尚未进行代码签名，Windows 可能显示“未知发布者”提示。请从本仓库的 Release 页面下载并核对发布资产。

安装包 SHA-256：`A98A85EC398793551BDEF87D8351E3B8E302C0A88150981601C80492FEE44801`

## 已知限制

- 目前只处理当前显示器。
- 文件图标来自 Windows 的 32×32 系统图标，高 DPI 下可能略显模糊。
- 暂无搜索和条目手动排序。

界面预览使用模拟文件名，不包含用户桌面内容。
